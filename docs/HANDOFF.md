## 2. 실행 방법 (중요 — 캐시 함정 있음)

```bash
# 프로젝트 루트에서. 캐시 없는 dev 서버를 "새 포트"로 띄운다.
python3 nocache_server.py   # 포트 8777, Cache-Control: no-store
```

미리보기: `http://localhost:8777/index.html`
- ⚠️ **일반 `python -m http.server`를 쓰면 브라우저가 JS 모듈을 캐시**해서 수정이 안 보인다(아래 6번 함정 참고). 반드시 no-store 서버 + 필요시 새 포트.

**새 PC에서 스크립트가 없을 때** — 아래 내용을 `nocache_server.py`로 저장하고 `python3 nocache_server.py` (경로만 본인 프로젝트 루트로 수정):
```python
import http.server, socketserver, os
os.chdir("/여기에/프로젝트/루트/경로")  # menu_calc 폴더 절대경로
class H(http.server.SimpleHTTPRequestHandler):
    def end_headers(self):
        self.send_header("Cache-Control", "no-store, max-age=0")
        super().end_headers()
socketserver.TCPServer.allow_reuse_address = True
with socketserver.TCPServer(("127.0.0.1", 8777), H) as httpd:
    httpd.serve_forever()
```

## 3. 파일 구조 & 아키텍처

```
index.html            # 셸. Wanted Sans(CDN) + style.css + main.js(module) 로드
css/style.css         # 디자인 토큰(:root) + 전체 스타일
js/
  main.js             # 진입점: mountApp→render, subscribe 재렌더, 클릭 라우팅, initAuth, 회원 폴더 클라우드 저장(디바운스)
  state.js            # 단일 상태 + 액션(폴더/메뉴 CRUD·정렬) + setUser/replaceFolders + subscribe/notify + 합계 파생 + LocalStorage(v2)
  ui.js               # 메인 화면 mountApp()(골격) + render()(폴더/목록/합계/계정아바타 갱신) + 빈메뉴 온보딩
  icons.js            # Lucide SVG 인라인 내장 + icon(name,{size,cls}) 헬퍼 (ISC, 자체호스팅)
  format.js           # 금액 포맷 공용: attachAmountFormatting/parseAmount/formatAmount (v0.7)
  firebase-config.js  # Firebase 웹앱 config(프로젝트 toksum-107fe) + isFirebaseConfigured() (v0.6)
  modules/
    overlay.js        # 바텀시트(backdrop+panel). 편집 시트/계정 시트/향후 퍼센트 모달에 재사용
    page.js           # 풀페이지 뷰 + history 뒤로가기 연동
    menuSettings.js   # 메뉴 설정 페이지(폴더/메뉴 CRUD, 정렬 모드, 바텀시트 편집, 금액 콤마)
    toast.js          # 하단 토스트(복사 완료 등 가벼운 피드백). showToast(msg) (v0.5)
    auth.js           # Firebase Google 로그인/로그아웃 + 세션복원 + 계정 바텀시트 + 로그인 시 클라우드 동기화 (v0.6~0.7)
    cloud.js          # Firestore 로드/저장: loadUserFolders/saveUserFolders (users/{uid}.folders) (v0.7)
  vendor/
    sortable.esm.js   # SortableJS 1.15.6 (MIT, 자체호스팅, ESM)
docs/                 # SPEC/UI/TODO(초안) + DESIGN.md + HANDOFF.md(이 문서)
```

**데이터 흐름(단방향):** 사용자 입력 → 상태 액션(state.js, `notify()`) → 구독자(main.js가 `render()`) 자동 갱신. UI는 상태만 바꾸면 화면이 따라온다.

**상태 모델:** `state = { folders:[{id,name,collapsed,menus:[{id,name,price,fav}]}], items:[{id,name,amount,qty,memo,type,menuId}], user }`. `items`는 견적 목록(계산 로직에서 채움). `amount`=단가, `qty`=개수, 줄 금액=단가×개수. `menuId`는 메뉴칩에서 온 항목만(같은 메뉴 개수 합치기 기준). `collapsed`=폴더 기본 접힘. `fav`=메뉴 즐겨찾기(v0.13, 메인 최상단 가상 폴더). (v0.10에서 `selected` 제거·`qty`/`menuId`/`collapsed` 추가)

## 5. 핵심 결정 & 문서(초안)와 달라진 점

> 규칙: docs(SPEC/UI/TODO)는 **초안**. 더 나은 방식은 적용하되 **바꿀 때 한 줄로 고지**, 기능 자체 생략은 먼저 확인. (사용자 지침)

- **아이콘**: Lucide(ISC) SVG를 `icons.js`에 **인라인 내장**(CDN 아님) → 오프라인·무의존.
- **드래그**: SortableJS(MIT) **ESM 자체호스팅**. 정렬은 평소 숨기고 "정렬 모드" 토글에서만 노출.
- **폰트**: **Wanted Sans**(OFL) jsdelivr CDN. (Pretendard→원티드산스로 교체함.) **유일한 외부 의존성**, 실패 시 시스템 폰트로 graceful fallback.
- **메뉴 설정 UI 여정**: 바텀시트 → 풀페이지(page.js) → **iOS 그룹리스트 + 탭시 바텀시트 편집 + 정렬모드**로 재설계(비좁음/번잡 해소).
- **헤더(컨텍스트 배치)**: `[견적 계산기]`(좌측 큰 볼드) ··· `[👤 계정]`(우). "메뉴 설정"은 헤더에서 빼고 **메뉴 섹션 헤더의 "관리 ›" 버튼**으로 이동(편집 대상 근처에 배치). 하단선은 평소 없고 **스크롤 시에만 hairline**(토스·iOS).
- **메인 화면 리디자인**: 설정 페이지처럼 **섹션 헤더 체계**(`.section-head`: 제목+우측 액션) 도입. 현재 "메뉴" 섹션에 적용, 견적 목록 섹션 헤더는 계산 로직 때 추가 예정.
- **금액 입력**: ~~`type=number`~~ → **`type=text inputmode=numeric pattern="[0-9,]*"`**(v0.5 변경). 콤마 표시·커서 제어를 위해 text로. `inputmode=numeric`으로 모바일 숫자 키패드는 유지. (실시간 콤마+앞 0 제거는 `main.js attachAmountFormatting`.)
- **디자인 시스템**: `docs/DESIGN.md`에 참고 앱/카드vs리스트/UX패턴/토큰 명문화.

## 6. 함정 & 해결 (재발 방지)

1. **브라우저 ES모듈 캐시(가장 큰 함정)**: 최초 `python -m http.server`가 캐시 헤더를 안 줘서, 이후 파일을 고쳐도 브라우저가 **옛 모듈을 fresh로 간주**해 실행. navigate/force/새 탭/쿼리스트링 다 실패(상대 import는 쿼리 상속 안 함). **해결: `Cache-Control: no-store` dev 서버 + 캐시가 전혀 없는 새 포트(8777)에서 로드.** 스크립트: `/tmp/nocache_server2.py`.
2. **오버레이 스크린샷 지연**: 미리보기 브라우저가 fixed 바텀시트를 캡처 못 하고 밑 페이지를 찍는 경우가 있음. → **read_page/JS로 DOM 검증**. 풀페이지(`.page`)는 일반 요소라 정상 캡처.
3. **SortableJS 드래그 자동화 불가**: 합성 드래그/마우스 이벤트로는 Sortable 시퀀스 재현 안 됨. → 인스턴스의 `options.onEnd({oldIndex,newIndex,from,to})`를 **직접 호출해 배선 검증**. (주의: onEnd 직접호출은 DOM을 실제로 안 옮겨서 DOM/상태가 어긋날 수 있음 → 검증 후 reload.)
4. **중첩 flex 오버플로우**: 중간 flex 컨테이너가 `min-width:auto`면 자식이 안 줄어 밖으로 튀어나감. → 중간 컨테이너에 **`min-width:0`**. (지금은 인라인편집을 시트로 대체해 해당 코드는 없어짐, 원칙만 기억.)
5. **AskUserQuestion JSON 파싱 에러**: preview에 박스드로잉/이스케이프 넣으면 깨짐 → preview는 단순 텍스트로.
6. **file:// 로 못 씀**: ES 모듈 import 때문에 반드시 http 서빙. GitHub Pages는 OK.

- **메뉴 즐겨찾기 = 행 별 아이콘 + 메인 최상단 가상 폴더** (v0.13) — 지정 방식은 **메뉴 설정 행 왼쪽 별 토글**(사용자 선택; 시트 토글 대안은 기각). 별 평소 회색 아웃라인, 지정 시 **그린 채움**(강조 1색). 데이터는 `menu.fav` 플래그 하나 — 별도 저장소·동기화 코드 없이 기존 folders 저장에 편승. 메인은 `favMenus()`(폴더순→메뉴순)가 1개 이상이면 폴더 섹션 맨 위에 **가상 폴더**(`state.folders`에 없음, 고정 id `__fav__`, 별 헤더). fav 칩은 원래 `menu-id`라 눌러도 원래 폴더 메뉴와 **menuId로 합쳐짐**(중복 줄 없음). 캐럿 접기 런타임. fav 0개면 폴더 숨김. `toggleMenuFav`는 설정 화면에서만 호출(별→`render()`; 메인은 notify로 자동).
- **가격 0 = "무료"** (v0.11, Option A) — 별도 플래그 없이 `price===0`을 무료로 간주. 메뉴 설정 "무료" 토글은 가격을 0으로 두는 단축. 표시는 `format.js`: 항목 단위(메뉴칩·견적 줄·복사·설정 행)는 `formatWonOrFree`(0→"무료"), **합계는 `formatWon`(0→"0원")** — 빈 목록/0 합계가 "무료"로 보이면 안 되므로. 할인(음수)은 그대로 금액.
- **금액 인풋 = 콤마 자동 + 앞 0 제거**, `type=text inputmode=numeric` (v0.5). number로 되돌리지 말 것(콤마·커서제어 불가).
- **50%/할인 = 입력액 기준 원탭** (v0.5) — 50%=입력액×0.5, 할인=입력액을 −로. 퍼센트 선택 바텀시트는 보류(원하면 나중에).
- **저장 = 메뉴 설정(폴더/메뉴)만** (v0.5) — 견적 목록(items)은 저장 안 함(사용자 확정). LocalStorage 로컬 한정. 나중에 items 저장을 추가하려면 사용자 확인 후.
- **실행취소 범위 = 견적 목록 변경만** (v0.5) — 폴더 접기·메뉴 설정 편집은 undo 대상 아님. 비우기(🗑)는 undo로 복구되므로 별도 확인창 두지 않음.
