# CHANGELOG

## v0.11 — 무료 메뉴 (2026-07-24)
> 메뉴를 "무료"로 등록 → 금액이 0원인 곳은 어디서나 **"무료"** 로 표시.

- **메뉴 설정 시트에 "무료" 토글** — 켜면 금액칸 비활성(placeholder "무료") + 저장 시 `price:0`. 편집 시 기존 가격이 0이면 자동으로 무료 켜짐. `.switch` 스타일 재사용(폴더 기본접힘 토글과 동일).
- **표시 규칙(Option A) = 가격 0 = "무료"** — 별도 플래그 없이 `price===0`을 무료로 간주. `format.js`에 `formatWon`(항상 원)·`formatWonOrFree`(0이면 "무료") 추가. 메뉴칩·견적 목록 줄 금액·복사 텍스트·메뉴 설정 행에 `formatWonOrFree` 적용. **합계(합계바)는 `formatWon`** 유지 — 빈 목록/0원 합계가 "무료"로 보이면 안 됨. 할인(음수)은 그대로 금액 표시.
- **변경 파일**: `format.js`(formatWon/formatWonOrFree), `ui.js`·`main.js`(칩·목록·복사 포맷), `menuSettings.js`(무료 토글 + 행 포맷), `style.css`(`.field:disabled`).

## v0.10 — 견적 목록 개편 + 폴더 기본 접힘 (2026-07-24)
> 다듬기 단계. 견적 목록의 실사용성을 크게 손봄 — 같은 메뉴 합치기·개수 조절, 체크박스 제거, 리스트를 hairline 한 줄 행으로. 폴더엔 "기본 접힘" 설정 추가.

- **폴더 "기본 열림/접힘" 설정** — 폴더 데이터에 `collapsed` 필드 추가(기본 `false`=열림). 폴더 수정 시트에 **"기본으로 접어두기" 토글**(iOS/토스식 스위치, `.switch`). 메인에서 캐럿으로 접었다 펴는 건 **런타임 임시**(새로고침하면 기본값으로 복귀), 설정값만 저장. `ui.js` `syncCollapseDefaults()`가 폴더별 기본값을 런타임 상태에 반영(런타임 토글은 유지, 기본값 변경 시 재적용). ⚠️ 접힘이 "UI 전용·비저장"에서 **"기본값은 저장"** 으로 바뀜(§10 갱신).
- **같은 메뉴 합치기 + 개수 조절** — item에 `qty`(개수)·`menuId` 추가, `amount`는 이제 **단가**(줄 금액 = 단가 × 개수). 같은 메뉴칩을 다시 누르면 새 줄 대신 **개수 +1**(`addMenuItem`이 `menuId`로 기존 항목 탐색). 각 행에 **`− n +` 스테퍼**(`changeItemQty`, 최소 1 — 삭제는 X). 직접입력/50%/할인은 각각 별도 줄(합치지 않음). 합계·복사 모두 개수 반영(복사: `명함 ×2  20,000원`).
- **견적 목록 체크박스 제거** — "삭제 안 하고 합계에서 잠깐 빼기"용 체크박스는 빠른 견적 앱엔 과함(사용자: "안 넣을 거면 그냥 삭제") → **합계·복사는 항상 목록 전체**, 빼려면 X 삭제(↶ 복구). `selected`/`toggleItem`/`selectedTotal` 제거, `grandTotal`로 통일. ⚠️ §10 "합계 = 체크된 항목만" 뒤집힘.
- **리스트 디자인 = hairline 한 줄 행** — 회색 채움(gray-100 pill) 제거 → **행 사이 hairline 구분선**(`--border`). `이름 · [− n +] · 금액 · X` 한 줄 컴팩트. 금액 `min-width:84px`+우측정렬+`tabular-nums`로 **금액·스테퍼가 세로 열로 정렬**. ⚠️ §10 "깊이감을 카드/회색 캔버스로 풀지 말 것 / 요소 gray-100 유지"를 사용자 지시로 hairline으로 전환.
- **변경 파일**: `state.js`(qty·menuId·합치기·changeItemQty·setFolderCollapsed, selected/toggleItem/selectedTotal 삭제), `ui.js`(리스트 행 마크업, collapse 기본값 반영), `main.js`(qty 라우팅·복사 전체·체크박스 리스너 삭제), `menuSettings.js`(폴더 시트 토글), `style.css`(`.switch`·`.qty-stepper`·리스트 hairline, `.list-check`/`.is-selected`/`.list-unit` 삭제).

## v0.7 — Firestore 동기화 + 데모 시드 제거 + 금액 포맷 공용화 (2026-07-23)
> 로그인의 실제 목적(다기기 메뉴 동기화) 완성. 신규 사용자 상태로 정리하고, 금액 콤마 포맷을 메뉴 설정 시트까지 확장.

- **Firestore 동기화(핵심, 실동작 확인)** — 로그인 사용자의 **메뉴 설정(폴더/메뉴)** 을 클라우드에 저장/복원. 견적 목록(items)은 여전히 저장 안 함.
  - 신규 `js/modules/cloud.js`: `loadUserFolders(uid)`/`saveUserFolders(uid, folders)`. Firestore SDK(gstatic v11.1.0) 동적 import, auth.js가 만든 Firebase 앱을 `getApp()`으로 재사용. 데이터 위치 `users/{uid}.folders`.
  - `state.js` `replaceFolders()` 추가. `auth.js` 로그인 시 `syncOnLogin(uid)`: **클라우드에 데이터 있으면 그걸로 반영(다기기 따라옴), 비어있으면(첫 로그인) 현재 로컬 폴더 업로드**.
  - `main.js` `maybeSyncFoldersToCloud()`: 회원이 폴더 변경 시 **800ms 디바운스**로 Firestore 저장(folders JSON이 실제 바뀐 경우만 — items 변경엔 안 씀). LocalStorage는 회원/비회원 공통으로 항상 저장(오프라인 대비).
  - 실패(미생성·권한·오프라인)는 catch → 토스트 + LocalStorage 자연 폴백, 앱 안 깨짐.
  - **콘솔 세팅(사용자 완료)**: Firestore(Standard, asia-northeast3) 생성 + 보안 규칙 `users/{uid}`는 `request.auth.uid == uid`인 본인만 read/write.
  - ✅ **검증됨**: 한 기기에서 메뉴 추가 → Firestore 저장 확인 → 다른 세션(미리보기)에서 같은 계정 로그인 시 메뉴 따라옴.
- **데모 시드 제거 → 신규 사용자 = 빈 메뉴**:
  - `seedFolders()`가 이제 빈 배열. 저장 키 `coverCalc.folders.v1`→**`v2`**(기존 브라우저의 옛 시드 자동 무시, 수동 삭제 불필요).
  - 빈 메뉴일 때 온보딩 안내(`ui.js` renderFolders): "아직 등록된 메뉴가 없어요 / 위 ⚙️ 관리에서 폴더와 메뉴를 추가해보세요"(`.menu-empty`). ※ 이건 **메뉴 섹션** 빈 상태로, §10의 "견적 목록 빈 상태 숨김"과는 별개.
- **금액 포맷 공용화 + 메뉴 설정 시트 적용**:
  - 신규 `js/format.js`: `attachAmountFormatting`(실시간 콤마+앞0제거+커서보존), `parseAmount`(콤마 제거→숫자), `formatAmount`(숫자→콤마문자열). main.js에 있던 로컬 포맷 로직을 이리로 이전(중복 제거).
