# DESIGN — 디자인 시스템 & UX 참고 기준

> 대기업 앱들의 검증된 디자인 시스템을 분석해 이 앱에 맞게 정리한 기준 문서.
> 새 화면/컴포넌트를 만들 때 **먼저 이 문서의 패턴에 맞는지** 확인한다.

## 1. 참고하는 디자인 시스템 & 앱

| 출처 | 핵심적으로 빌려오는 것 |
|---|---|
| **토스(Toss)** | 미니멀 헤더, 큰/굵은 숫자, 바텀시트 편집, 하단 단일 CTA, 그룹 리스트, 넉넉한 여백 |
| **Apple HIG / iOS 설정** | 그룹형 inset 리스트, 편집(정렬)모드 토글, 폼 시트, 스와이프 액션 |
| **Material 3(Google)** | 명확한 elevation 위계, 상태 레이어(press/hover), FAB/주요 액션, 바텀시트 |
| **배달의민족·쿠팡** | 장바구니 리스트 행, 수량 스테퍼, 하단 sticky 합계/결제 바, 상품 카드 |
| **카카오페이·카카오뱅크** | 금액 강조, 깔끔한 리스트 행, 토스트 피드백 |

## 2. 카드 vs 리스트 — 언제 무엇을 쓰나

대기업 앱 공통 원칙을 이 앱에 적용:

- **리스트(행)** — 같은 형태가 반복되고 스캔이 목적인 것.
  - 예: 견적 목록, 메뉴 설정(그룹 리스트), 향후 저장된 견적 목록.
  - 토스·iOS 설정 방식: 배경 그룹 컨테이너 + 얇은 구분선 + 탭 시 바텀시트.
- **카드** — 서로 다른 성격의 콘텐츠 블록을 구분할 때.
  - 예: (향후) 계정/동기화 상태 요약, 프로모션·안내 블록.
  - 카드를 남발하지 않는다. "카드 안에 카드" 금지(위계 혼란).
- **칩(pill)/버튼** — 빠른 선택·토글.
  - 예: 폴더별 메뉴 선택 버튼, `50%`·`-할인` 액션.

> 현재 메뉴 설정은 카드→**그룹 리스트**로 전환 완료. 견적 목록도 리스트 기반.
> **견적 목록 행(v0.10)**: 배민·쿠팡 **장바구니 행** 참고 — `이름 · 수량 스테퍼(− n +) · 금액 · 삭제` 한 줄. 회색 채움 없이 **hairline 구분선**(다른 요소의 gray-100 채움과 달리 리스트만 예외), 금액 우측 고정 열 정렬. 같은 메뉴 재선택 시 개수 합치기.

## 3. UX 인터랙션 패턴

- **화면당 주요 액션 1개**: 하단 고정 CTA(토스). 이 앱은 하단 합계바가 그 역할.
- **바텀시트 우선**: 빠른 편집/선택은 페이지 이동 대신 바텀시트(토스·iOS). (메뉴 수정, 퍼센트 선택 예정)
- **점진적 노출(Progressive disclosure)**: 드래그·삭제 등은 평소 숨기고 "정렬/편집" 모드에서만 노출(iOS 설정).
- **즉시 피드백**: 복사·완료는 토스트, 버튼은 press 시 scale/색 변화(Material 상태 레이어).
- **파괴적 동작**: 빨강 + 확인(삭제/비우기).
- **빈 상태(empty state)**: 안내 문구로 다음 행동 유도.
- **수량 개념이 필요해지면**: 배민·쿠팡식 스테퍼(− n +) 검토.

## 4. 비주얼 토큰 (css/style.css `:root`)

- **폰트**: Wanted Sans (OFL). 굵기 위계 500/600/700/800, letter-spacing 약간 음수.
- **컬러**: 메인 그린 `#0CA678`(주요, v0.6부터 — 기존 토스 블루 `#3182F6`에서 전환. 밝고 청량한 에메랄드, 흰 글씨 대비 안전선 근처), 그레이스케일 `#F9FAFB`~`#191F28`, 할인 레드 `#F04452`. 강조는 화면당 1색(그린) 원칙 유지.
- **여백**: 8pt 그리드(4·8·12·16·20·24·28).
- **라운드**: sm 12 / 기본 16 / lg 20, 알약 999.
- **그림자**: 아주 옅게(토스). 강한 그림자 지양.
- **터치 타깃**: 최소 40–44px(모바일).

## 5. 로고 / 브랜드 마크 (v0.9 확정)

- **심볼 = "T·"** — 잉크 T(#191F28) + **초록 탭닷**(#0CA678). T가 아래 점을 "톡 누르는" 관계 → 이름(톡톡 눌러 셈) 은유. 점은 마침표가 아니라 탭 포인트.
- **확정 좌표**(100 기준 viewBox): 크로스바 `x24 y25 w52 h13 rx6.5`, 세로획 `x43.5 y25 w13 h36 rx6.5`(아래끝 61, "살짝 줄임"), 점 `cx50 cy76 r7.5`. 세로획을 줄이고 점을 살짝 올려 균형.
- **가로 락업**(심볼+톡셈): 실무 표준대로 **심볼 실루엣 = 글자높이, 수직 중앙정렬**. 비율 심볼:글자 = **32.5:34**, 간격은 글자비율(≈0.23em, 헤더에선 gap 7 / 스크롤 16px 심볼 gap 5). 심볼이 글자보다 커지지 않게(중요 — 커지면 아마추어 느낌). 근거: Android 파트너 가이드·Akrivi lockup 그리드.
- **잉크 T는 `currentColor`** 로 그려 문맥색 상속(라이트/다크·헤더색 대응), 점만 `--primary`.
- **앱/파비콘 아이콘 = 라운드 사각**(rx26) + **흰 글리프 중앙정렬**. **다크 사각이 기본**(`favicon.svg`·`apple-touch-icon`, 점만 그린) / 그린 사각은 대안(`assets/toksum-icon-green.svg`). 심볼 단독 마크는 `assets/toksum-symbol.svg`.
- ⚠️ **"톡! 터치 느낌"은 정적 로고에 리플로 넣지 않는다**(한 줄 호가 괄호처럼 보여 오히려 지저분). 탭 손맛은 **모션(스플래시/버튼 리플)** 으로 살리기로 결정.
- **미적용(다음)**: iOS `apple-touch-icon`·PWA maskable은 **PNG 래스터 필요**(현재 SVG만) → PWA 셸 단계에서 생성.

## 6. 적용 원칙

1. 새 화면은 위 패턴 중 하나에 매핑해서 시작한다.
2. 문서(SPEC/UI)와 다르게 가면 한 줄로 이유를 남긴다.
3. 어떤 앱의 어떤 패턴을 참고했는지 구현 시 언급한다.
